# ⚛️ Nuclear Script — 3D-демо АЕС

Інтерактивні Three.js-візуалізації атомної електростанції та ядерного реактора, створені для навчальних цілей.

## Демо-сцени

| Файл | Назва | Опис |
|------|-------|------|
| [`plant-basic.html`](plant-basic.html) | АЕС — базова сцена | Реакторний корпус, дві градирні з анімованою парою, машинний зал, димова труба, ставок-охолоджувач, допоміжні будівлі, паркан |
| [`plant-extended.html`](plant-extended.html) | АЕС — розширена сцена | Усе з базової сцени + підстанція з трансформаторами та шинами, адмінкорпус зі скляним фасадом, склад, ЛЕП з опорами та проводами, дороги, ліхтарі |
| [`reactor-cutaway.html`](reactor-cutaway.html) | Реактор — розріз | Спрощена 3D-модель PWR-реактора у розрізі: корпус реактора, теплоносій, активна зона, паливні та керуючі стрижні. CSS2D-підписи, перемикачі видимості шарів |

Відкрийте [`index.html`](index.html) для навігаційної сторінки зі списком усіх сцен.

## Запуск

Файли є статичними HTML і не потребують збірки. Достатньо відкрити будь-який файл у браузері.

> **Примітка:** Three.js та пов'язані модулі завантажуються через CDN (jsDelivr). Для запуску потрібне інтернет-з'єднання.

**Рекомендований спосіб** — запустити локальний HTTP-сервер, щоб уникнути CORS-обмежень:

```bash
# Python 3
python -m http.server 8080
# або Node.js
npx serve .
```

Потім відкрийте <http://localhost:8080> у браузері.

## Технологічний стек

- [Three.js](https://threejs.org/) r160 — 3D-рушій
- `OrbitControls` — навігація камерою
- `CSS2DRenderer` — HTML-підписи у 3D-просторі (тільки `reactor-cutaway.html`)
- Чистий HTML/CSS/JS без системи збірки

## Можливі покращення

- Виокремити спільний JS-код ініціалізації (сцена, камера, рендер, освітлення) у `js/common/setup.js`
- Централізувати матеріали в `js/common/materials.js`
- Перейти на [Vite](https://vitejs.dev/) або інший інструмент збірки для роботи з модулями без CDN
- Додати підписи до об'єктів базової та розширеної сцен (аналогічно `reactor-cutaway.html`)
- Використати `InstancedMesh` для повторюваних елементів (ліхтарі, опори ЛЕП, паркани)
